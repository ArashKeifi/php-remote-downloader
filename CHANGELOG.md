## [1.0.0] - 2026-10-28

### Added

- Resumable and adaptive chunked remote downloads
- Parallel queue processing and per-download multipart connections
- Live speed, ETA, total progress, and per-chunk progress display
- Pause, resume, retry, delete, and duplicate-file conflict handling
- Restricted destination-directory browser for shared hosting
- Persistent runtime queue and CLI Cron worker
- Administrator authentication, CSRF protection, and app-local sessions
- URL validation, SSRF protection, and safe destination handling
- Selective cPanel Full Backup inspection and recovery
- Recovery workflows for web files, MySQL databases, Maildir data, and email accounts
- Persian responsive dashboard
